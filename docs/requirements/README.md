## 進め方

CLAUDE.md「8. Claude Code への重要ルール」に従い、以下のサイクルで確定させる。

1. Claude が実務的な叩き台を作成
2. 採用理由・メリット・デメリットを提示
3. オーナーがレビュー
4. 必要に応じて修正
5. 合意したものを確定事項としてドキュメントへ反映（叩き台のうち未合意の箇所は
   `open-issues.md` に残し、本文には「【要承認】」を明記する）
