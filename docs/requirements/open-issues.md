## B4（確定）: メンテナンス履歴の項目

2026-09-04 確定。物理設計は Phase 4、入力仕様は 9 章で正式化。

| 項目 | 型（目安） | 必須 | 補足 |
|---|---|---|---|
| 対象サーバー | FK(`servers`) | ✅ | 論理削除済みサーバーへの新規登録は不可 |
| 実施日 | date | ✅ | **日付のみ**（時刻は持たない。必要なら「影響・ダウンタイム」欄に記述）。将来 timestamp 化の余地 |
| 種別 | enum | ✅ | `patch`（パッチ適用）/ `config`（設定変更）/ `hardware`（ハード交換）/ `other`（その他） |
| 作業者 | 文字列（255） | ✅ | MVP はフリーテキスト |
| 作業内容 | 文字列（2000） | ✅ | |
| 影響・ダウンタイム | 文字列（1000） | 任意 | |
| 結果・備考 | 文字列（1000） | 任意 | |
| 登録日時 / 更新日時 | timestamp | ✅（自動） | |

- **MVP では履歴の編集・削除を行わない**（登録・参照のみ）。誤登録時の扱いは将来検討。
- メンテナンス履歴も論理削除カラム（`deleted_at`）を持つ（`CLAUDE.md` §3）。UI からは削除しないが、
  スキーマ上は保持し、将来の「取り消し」機能の余地とする。
