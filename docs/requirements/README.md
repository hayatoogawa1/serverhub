## 進め方（確定済み）

以下のサイクルで v1.0 まで確定させた。

1. Claude が実務的な叩き台を作成 → 2. 採用理由・メリデメを提示 → 3. オーナーがレビュー →
4. 必要に応じて修正 → 5. 合意分を確定事項として反映（未合意は `open-issues.md` に残す）

以降の仕様変更は `CLAUDE.md` §7 の手順（影響調査 → 設計 → 実装 → テスト → ドキュメント）に従う。
